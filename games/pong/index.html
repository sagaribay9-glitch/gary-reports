Pong

The one that started it all.

Two paddles, one ball, no mercy

Pong is being rebuilt in Unity for local two-player play. Paddle contact changes the ball's return angle, keeping rallies readable.

It is in development for Windows.

What's in it

Paddle returns

The ball's return angle changes with paddle contact position.

Match feedback

Hit sounds and score changes make each rally easy to follow.

Local duels

Two players can share one machine.

Simple controls

Move your paddle and track the ball.
